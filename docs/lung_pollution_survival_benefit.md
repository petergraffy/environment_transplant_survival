# Primary analysis: lung pollution and transplant RMST benefit

Designated primary analysis November 2, 2026. The primary endpoint is one-year
RMST benefit, in days, with pointwise 95% confidence intervals. Survival-probability
differences are supporting outcomes. Earlier waitlist analyses are retained in
`code/archive/pre_lung_rmst/` as historical code and cohort provenance.

This implements the requested simple observational extension of the prior lung
models: separate time-varying Cox models before and after transplantation, then
paired absolute survival predictions. There is no target-trial emulation,
propensity weighting, artificial-censoring weighting, or allocation simulation.

## Run

The complete primary workflow is:

```powershell
Rscript code/run_primary_lung_analysis.R
```

Use `--reuse-fitted` to reproduce RMST figures and confidence intervals from
the existing fitted cache and matching bootstrap checkpoints. The runner
fixes the horizon at 365 days and runs stages in separate R processes. It does
not run the optional secondary survival-probability bootstrap in script 92.

`code/00_prepare_lung_primary_inputs.R` verifies the existing LAS-era inputs or
builds the required private caches using the established archived cohort
functions. On a fresh setup it prepares the original deduplicated cohort,
baseline covariates, registration/outcome linkage and official LAS history,
then invokes the archived LAS-era preparation. It does not fit the historical
four-organ models or run their sensitivity analyses. This preserves the current
cohort definitions rather than replacing them during the archive transition.

Run from the repository root with the existing R libraries and local Q1 2026 SAFs:

```powershell
Rscript code/tests/test_lung_survival_benefit.R
Rscript code/91_lung_pollution_survival_benefit.R
```

Script 91 defaults to point estimates, seed 20261102, and a 365-day prediction
horizon. Script 92 defaults to 200 joint person bootstrap resamples. Bootstrap
refits are substantially slower than the initial six models; they are a separate
explicit step. To fit point estimates and then calculate uncertainty:

```powershell
$env:LUNG_BENEFIT_BOOTSTRAPS = '0'
Rscript code/91_lung_pollution_survival_benefit.R
$env:LUNG_BENEFIT_BOOTSTRAPS = '200'
Rscript code/92_lung_pollution_benefit_bootstrap.R
```

Script 92 explicitly reads the completed local model cache and reruns only
uncertainty estimation and plots. It does not refresh source data. Rerun script
91 after changing sources, cohort definitions, exposure construction or models.
To refit against a deliberately selected existing prepared dataset, set
`LUNG_BENEFIT_USE_PREPARED='1'` for script 91. The default is `0` and refreshes
preparation from source. Unset the override before the next source refresh.
`LUNG_BENEFIT_OUTPUT`, `LUNG_BENEFIT_HORIZON_DAYS` (script 91), and
`LUNG_BENEFIT_SEED` are optional overrides. Both scripts execute in the foreground
and write progress messages, which can be redirected to a file in `logs/`.

Prerequisite: the existing audited LAS-era preparation at
`output/revision_2026_checklist/cache/las_era_lung/prepared.rds`, generated by
scripts 29 and 30 under `code/archive/pre_lung_rmst/revision_2026/`. It supplies the prior deduplicated
lung cohort, ACS vulnerability proxy, and official calculated LAS histories.
PM2.5/O3 use published daily releases, aggregated through the existing
content-keyed monthly reader. Monthly and annual NO2 releases are also required.

## Population, linkage and mortality

- Adults listed January 1, 2006 through March 8, 2023, using the existing
  person-level deduplication, first listing covariates, ZIP and center.
- Exclude other-organ candidates using the prior cohort's multi-organ flag and
  previous lung/heart-lung recipients at the index registration. The flag
  reflects other-organ candidacy anywhere in the underlying cohort; it is not
  a new contemporaneous multiorgan-transplant eligibility definition.
- First documented lung transplant is the earliest candidate or lung-follow-up
  transplant date across a person's registrations. Link follow-up by person;
  receiving registration can differ from first listing registration. Documented
  transplants before listing are excluded, guarding against missed prior grafts.
  A transplant-coded removal without any linked transplant date censors
  pretransplant follow-up at removal and does not create a postoperative record.
- Reconcile OPTN, SSA, candidate death/removal, and deceased follow-up dates.
  Use the earliest documented date and report date disagreements. A death
  before listing excludes the record; a transplant recorded after death cannot
  initiate postoperative follow-up.
- Pretransplant follow-up: listing until death, transplant or March 8, 2023.
  Delisting/deterioration is not itself death and does not end mortality follow-up.
  For delisted candidates without a recorded death this assumes registry death
  ascertainment remains available through administrative end.
- Posttransplant follow-up: LAS-era transplant until documented death, otherwise
  last known alive, capped December 31, 2024. Later death linkage can extend
  beyond the last follow-up form. All-cause survival can continue through a later
  transplant when mortality/follow-up is available; graft failure is not an event.
- A death on transplant day belongs only to the posttransplant model and is
  assigned 0.5 postoperative day. Other intervals use exact elapsed days and
  nonoverlapping `(start, stop]` intervals. A boundary-day death belongs to the
  interval ending that day.

These restrictions keep waitlist LAS adjustment within its valid era, while
allowing postoperative pollution to update through 2024. The study does not
assume the recipient-selected CAS supplement is a complete candidate history.

## Exposures and adjustment

Fit one model per pollutant and phase: six models in total. Exposures update at
calendar-month boundaries using the **previous complete calendar month**.
PM2.5 and O3 are derived from daily releases using the prior reader's minimum
20 observed days per source month. NO2 uses monthly means beginning with the
available monthly source. Before that source starts, use the previous calendar
year relative to the risk interval's year, including for January intervals.
No annual value fills a missing month within the monthly-source era. This
annual fallback is lagged rather than the future-containing same-year fallback
used by some older scripts. Quantify fallback person-time in the NO2 results.

Use the same prior LAS-era time-varying adjustment:

`age + sex + race + zcta_svi_proxy + las_per10 + las_unavailable + strata(listing_center)`

Age is age at listing before transplant and age at transplant afterward. Before
transplant, official LAS is updated at interval starts using only measurements
already available. After transplant, LAS is the last available pretransplant/
transplant-date value and remains fixed. Missing LAS uses the prior preparation's
reference median plus a missing indicator. A constant missing indicator is
omitted. There is no under-12 indicator in this adult cohort.

Retain listing ZIP, listing-year vulnerability and first listing-center strata
in both phases to maintain the existing covariate definitions and paired
prediction strata. No new donor, calendar-year, or transplant-procedure
adjustment is silently added. This preserves the requested model but leaves
calendar/geographic confounding and residential relocation as limitations.

Use complete eligible intervals, Efron ties, and person-clustered robust
coefficient standard errors. Hazard ratios are per 5 ug/m3 PM2.5 or 10 ppb
NO2/O3. The endpoint is all-cause mortality, replacing the prior adverse
death/deterioration composite.

## Paired survival predictions

For each pollutant, use recipients represented in both fitted phase models,
with complete prediction covariates and support for the full horizon. Both
predictions are averaged over this same recipient population. The reference
population can differ across pollutants because of missingness and support;
comparisons between pollutant curves are not direct head-to-head effects.

For a recipient transplanted after `w` waiting days, predict at horizon `h`:

```text
S_without(h | survived to w) = exp(-(H0_pre(w+h)-H0_pre(w)) * exp(lp_pre))
S_after(h)                   = exp(-H0_post(h) * exp(lp_post))
benefit(h)                   = S_after(h) - S_without(h | survived to w)
```

Use each recipient's own center baseline hazards and phase-specific age
definition. Freeze LAS and pollution at the decision-date scenario for future
prediction. This does not claim to forecast future disease progression or
exposure trajectories. The subtraction of `H0_pre(w)` is essential: survival
without transplant is conditional on survival up to the same decision date,
not survival from initial listing.

Require at least five people in each center's modeled phase cohort still under
follow-up at the required prediction endpoint (`w+h` before transplant, `h`
afterward). Do not extend a center's cumulative hazard beyond observed support.
These are follow-up checks, not guarantees of treatment exchangeability.

The 21-point exposure grid spans the intersection of the two fitted models'
10th-to-90th percentile ranges of eligible monthly intervals. Report both
survival components, their difference, and the difference in benefit between
the highest and lowest grid concentrations. The latter is an absolute
effect-modification contrast on the survival-probability scale, expressed in
percentage points; it is not a comparison of pollution HRs.

Bootstrap people jointly across phases using multiplicity weights in Cox
refits; keep the empirical reference recipients fixed. Percentile bands are
pointwise and conditional on that reference population. Failures are recorded.
Zero or very few successful replicates do not provide reliable uncertainty;
the bootstrap command's default 200 is intended for the full analysis, with more resamples possible
for final publication.
Confidence intervals are suppressed unless at least 100 and at least 80% of
requested resamples succeed for that pollutant. `confidence_status` explicitly
distinguishes completed uncertainty estimates from point-estimate/debug runs.

## Outputs and interpretation

All outputs are under `output/lung_pollution_survival_benefit/` by default:

- `cohort_flow.csv`, `linkage_audit.csv`, `source_inventory.csv`.
- `pollutant_results.csv`: phase-specific mortality HRs, intervals, people,
  deaths, person-years and NO2 annual-fallback person-time.
- `model_log.csv`: exact formulas and model warnings.
- `survival_benefit_curves.csv`: paired standardized survival and benefit;
  bootstrap confidence limits when requested.
- `benefit_exposure_contrasts.csv`: high-minus-low exposure benefit contrast.
- `bootstrap_log.csv`, `bootstrap_curves.csv`: uncertainty audit and replicates.
- `survival_benefit.png` and `.pdf`, `methods.txt`, `session_info.txt`.
- Ignored `cache/`: restricted prepared records, fitted models and prediction
  recipients. No patient-level tables are exported to versioned outputs.

Report **adjusted model-based transplant survival benefit by pollution exposure**.
Transplantation informatively removes candidates from pretransplant risk sets;
these models do not correct that selection beyond measured Cox adjustment.
They do not identify causal transplant effects or the effects of lowering
pollution. Pollution-associated differences in benefit can reflect measured or
unmeasured differences between candidates/recipients, model assumptions and
residual selection. Scripts 91/92 report one-year survival-probability benefit.
The separate RMST extension below reports expected days alive over one year.

## One-year RMST curves

After fitting the six models, run:

```powershell
Rscript code/tests/test_lung_rmst.R
Rscript code/93_lung_pollution_rmst.R
```

Script 93 reuses the existing fitted cache and the same paired recipients,
exposure grid, center strata and frozen covariates. It integrates each fitted
step-survival curve exactly over 365 days. Before transplant, the baseline
hazard is shifted by each recipient's prior waiting time and survival is
conditional on reaching that decision date. RMST is expressed in days alive;
RMST benefit is posttransplant RMST minus no-transplant RMST. It is not the
365-day survival-probability difference multiplied by 365.

Outputs in the same analysis directory:

- `rmst_1yr_exposure_curves.csv`: RMST with/without transplant and days gained
  across all 21 exposure scenarios.
- `rmst_1yr_exposure_contrasts.csv`: low/high exposure RMST benefit and its
  difference in days.
- `rmst_1yr_time_curves.csv`: accumulated RMST through the first year at the
  lowest and highest evaluated exposures, using the same supported population
  at every horizon.
- `rmst_1yr_benefit`, `rmst_1yr_components`, and `rmst_1yr_time`, each as PNG/PDF.
- `rmst_methods.txt`: integration and interpretation details.

Script 93 produces point estimates. For pointwise 95% confidence intervals, run:

```powershell
Rscript code/tests/test_lung_rmst_bootstrap.R
$env:LUNG_RMST_BOOTSTRAPS = '200'
$env:LUNG_RMST_WORKERS = '12'
Rscript code/94_lung_pollution_rmst_bootstrap.R
Rscript code/tests/validate_lung_rmst_confidence_intervals.R
```

Script 94 resamples people jointly across both phases and all three pollutants.
Each replicate refits both Cox models, estimates their baseline hazards, and
reintegrates RMST. The reference recipients, exposure grid and future covariate
scenarios remain fixed. This propagates coefficient and baseline-hazard
uncertainty and preserves dependence between the two phases. The 2.5th and
97.5th percentiles give pointwise 95% intervals for each RMST component, RMST
benefit, and within-replicate higher-minus-lower exposure benefit contrast.
These are not simultaneous confidence bands for the entire curve.

Warm starts and exact integration on shared date-derived event knots reduce
runtime without changing the model or approximating the RMST area. Parallel
workers load compact model inputs; the default caps workers at 12. Reduce
`LUNG_RMST_WORKERS` when sharing CPU/memory with other analyses. Local worker
sockets must be permitted by the execution environment. No source SAF reads
are required by script 94.

Completed replicates are checkpointed under ignored
`cache/rmst_bootstrap/<signature>/`. Rerun the same command to resume; increase
`LUNG_RMST_BOOTSTRAPS` to extend the run. The signature includes the fitted model
cache, method code, software versions and seed. Changing worker count does not
change random draws. Replicates lacking follow-up support for the complete fixed
reference population or with nonconvergence are recorded as failures, rather
than changing the reference population for individual resamples. At least 100
and 80% of requested resamples must succeed per pollutant before intervals are
displayed. Inspect `rmst_bootstrap_log.csv` for failure patterns.

The updated curve tables include `_low`, `_high`, `_se`,
`successful_bootstraps` and `confidence_status`. All three PNG/PDF plots gain
shaded intervals. `rmst_bootstrap_exposure_curves.csv`,
`rmst_bootstrap_time_curves.csv`, `rmst_bootstrap_timing.csv`,
`rmst_bootstrap_run.csv` and `rmst_bootstrap_methods.txt` provide the uncertainty
audit. Rerunning script 93 resets curves to point estimates; rerun script 94 to
reattach intervals from its matching checkpoints.

The pre-existing survival-probability bootstrap tables cannot be converted
into RMST confidence intervals. Tests verify exact integration, shifted
decision dates, warm-start equivalence, joint resampling, parallel execution,
checkpoint resumption, percentile calculations and ribbon rendering.

## Verification

`code/tests/test_lung_survival_benefit.R` uses synthetic data to verify monthly
boundaries, leap-year follow-up, perioperative deaths, completed-month exposure,
LAS timing, person bootstrap refits, and horizon support. It checks conditional
survival numerically against `survival::survfit` with center strata and nonzero
waiting time. Source-data runs should additionally inspect linkage discrepancies,
model warnings, event/sample counts and bootstrap success before interpretation.
Run `Rscript code/tests/validate_lung_survival_benefit_outputs.R` to check the
real-data outputs and export `validation_checks.csv` and
`complete_case_coverage.csv`. The synthetic test also runs all six models and
the separate bootstrap/report command with five smoke-test resamples in an
ignored validation directory; these are not clinical study estimates.

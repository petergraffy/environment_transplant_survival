# Analysis documentation

The current primary analysis is **lung transplant survival benefit by PM2.5,
NO2 and O3 exposure**, measured using one-year RMST with pointwise 95%
confidence intervals. Start with
[`lung_pollution_survival_benefit.md`](lung_pollution_survival_benefit.md).

Other modeling and manuscript-revision notes in this directory describe earlier
waitlist studies or proposed future work. They are retained for provenance and
do not supersede the current primary specification.

Exposure-source and release documentation remains relevant to the shared
inputs, especially `daily_pollution_analysis_inputs.md`, `monthly_no2_zcta.md`,
`daily_o3_zcta.md` and `lghap_daily_pm25_zcta.md`.

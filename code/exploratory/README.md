# Exploratory and Legacy Scripts

This folder contains exploratory, diagnostic, legacy, and non-primary analysis
scripts retained for transparency. They are not required to reproduce the
primary manuscript results.

Examples include early baseline-exposure models, time-varying pollution models,
competing-risk experiments, dynamic landmark/AUC analyses, gridMET aggregation
helpers, and SAF dictionary/data-structure checks.

Run scripts from the repository root if needed; many depend on local data paths
and intermediate outputs created during earlier analysis phases.
